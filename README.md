
# Контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием CSS-фреймворка Bootstrap.

В рамках контрольной работы реализованы главная страница, каталог товаров, страница подробного описания товара и форма оформления заявки.

## Практическая работа №9

**Тема:** Разработка главной страницы с использованием Bootstrap-сетки.

Выполнено:

- подключён Bootstrap через CDN;
- подключён собственный файл `css/custom.css`;
- создана шапка страницы;
- реализована Bootstrap-навигация;
- создан hero-блок с использованием сетки Bootstrap;
- добавлен блок преимуществ;
- создана адаптивная сетка популярных товаров;
- добавлен подвал страницы.

## Практическая работа №10

**Тема:** «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация на все страницы;
- создана страница каталога `catalog.html`;
- создана страница подробного описания товара `product.html`;
- создана страница оформления заявки `order.html`;
- реализованы карточки товаров с использованием Bootstrap;

- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`.

## Используемые технологии

- HTML5;
- CSS3;
- Bootstrap 5.3.8;
- Git;
- GitHub.

## Подключение Bootstrap

В проекте используется Bootstrap версии 5.3.8, подключённый через CDN.

Собственные стили размещены в файле `css/custom.css`, который подключается после Bootstrap.

Для работы интерактивных компонентов используется Bootstrap JS Bundle.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — страница подробного описания товара;
- `order.html` — форма оформления заявки;
- `css/custom.css` — дополнительные стили проекта;
- `images/` — папка для изображений проекта;
- `README.md` — описание проекта;
- `.gitignore` — файл исключений Git.

## Реализованные Bootstrap-компоненты

В проекте используются следующие компоненты:

- `navbar` — единая навигация между страницами;
- `card` — карточки товаров и оформление формы;
- `btn` — кнопки действий;
- `badge` — метки товаров;
- `alert` — информационные сообщения;
- `modal` — модальное окно быстрой заявки;
- `form-control` — поля ввода;
- `form-select` — выпадающий список выбора товара;
- `input-group` — группа элементов поля телефона;
- `form-check` — чекбокс согласия;
- `accordion` — раскрывающийся блок вопросов и ответов.

## Адаптивность

Для создания адаптивного интерфейса используется Bootstrap-сетка с классами `container`, `row`, `col-12`, `col-md-*`, `col-lg-*` и `g-*`.

Расположение элементов изменяется в зависимости от ширины экрана. Страницы рассчитаны на просмотр с компьютеров, планшетов и мобильных устройств.
