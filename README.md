# SpookyShop — контрольная работа №2

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

SpookyShop — учебный многостраничный интернет-магазин товаров для Хеллоуина. Интерфейс построен на Bootstrap: сетка, навигация, карточки товаров, формы и интерактивные компоненты.

На сайте представлены 18 товаров. Подробная страница реализована на примере костюма скелета: все кнопки «Подробнее» в каталоге ведут на `product.html`. Для оформления демонстрационной заявки можно выбрать любой товар в форме заказа.

Формы проверяются в браузере. Отправка на сервер, оплата и сохранение заказов не реализованы. После успешной проверки формы появляется сообщение о демонстрационном режиме.

## Используемые технологии

- HTML5;
- CSS3;
- Bootstrap 5.3.8;
- JavaScript;
- Git и GitHub для работы с репозиторием.

## Подключение Bootstrap

Bootstrap подключён локально, без CDN:

- `vendor/bootstrap/css/bootstrap.min.css` — стили;
- `vendor/bootstrap/js/bootstrap.bundle.min.js` — JavaScript Bootstrap вместе с Popper.

На каждой странице `css/custom.css` подключён после Bootstrap CSS, а Bootstrap JS Bundle — перед закрывающим тегом `</body>`.

Локальные файлы обеспечивают работу оформления и компонентов без загрузки Bootstrap из интернета. Для внешней Яндекс Карты на странице контактов требуется интернет.

## Структура и страницы проекта

- `index.html` — главная страница: приветственный блок, карусель, преимущества и популярные товары.

- `order.html` — форма оформления заявки.
- `contacts.html` — контакты, Яндекс Карта, форма обратной связи и модальное окно обратного звонка.
- `css/custom.css` — дополнительные стили сайта.
- `js/main.js` — фильтрация каталога, выбор товара в заказе и обработка форм.
- `images/` — изображения товаров и фонов.
- `vendor/bootstrap/` — локальные файлы Bootstrap.
- `README.md` — описание проекта.
- `.gitignore` — исключения для Git.

Общее меню содержит ссылки «Главная», «Популярные товары», «Каталог», «Заказ» и «Контакты». Ссылка на популярные товары ведёт к разделу главной страницы. Страница товара доступна через каталог.

## Фильтрация каталога

Фильтры применяются кнопкой «Применить»:

- тип товара: костюмы и маски, декор и освещение, грим и эффекты, игры и сладости;
- статус: хиты продаж, новинки, товары со скидкой;
- цена: нижняя и верхняя границы.

Внутри одной группы выбранные варианты объединяются по ИЛИ, между группами — по И. Пустые группы и незаполненные границы цены не ограничивают выбор.

После применения обновляется число найденных товаров. При отсутствии совпадений появляется сообщение. Чтобы вернуть весь каталог, нужно снять отметки, очистить цены и нажать «Применить».

## Формы и JavaScript

Файл `js/main.js` подключён на страницах каталога, заказа и контактов. Он отвечает за:

- применение фильтров и обновление счётчика товаров;
- выбор товара в заказе по параметру `product` в адресе;
- показ сообщений после проверки форм;
- скрытие сообщений при изменении или сбросе формы;
- сброс формы обратного звонка при открытии модального окна.

Кнопка «Заказать» на странице скелета ведёт на `order.html?product=skeleton`. В форме автоматически выбирается костюм скелета.

Обязательные поля проверяются средствами браузера. В форме обратного звонка телефон вводится в формате `+7 (900) 000-00-00`.

## Оформление и адаптивность

Основная вёрстка использует Bootstrap-сетку `container`, `row`, `col-12`, `col-md-*`, `col-lg-*` и отступы `g-*`. Популярные товары и каталог перестраиваются по ширине экрана. Фильтры располагаются слева на больших экранах и над товарами на меньших.

Собственный `custom.css` задаёт фоновые изображения, размеры фотографий, оранжевые акценты и оформление карты. Карточки популярных товаров, преимуществ и каталога имеют тёмный фон. Контактный блок на главной оформлен оранжевым.

Таблица характеристик помещена в `table-responsive`. У изображений есть `alt`, у полей — подписи, у кнопки мобильного меню — атрибуты доступности. Сообщения о результатах проверки форм используют `role="status"`.

## Запуск и проверка

Распакуйте проект и откройте `index.html` в браузере, сохранив структуру папок.

1. Проверьте переходы между страницами и ссылку «Популярные товары».
2. На главной переключите слайды карусели и откройте каталог.
3. В каталоге примените фильтры отдельно и совместно. Проверьте счётчик, пустой результат и возврат всех товаров после очистки условий.
4. Откройте страницу товара через «Подробнее», проверьте таблицу и три вопроса аккордеона.
5. Нажмите «Заказать» и убедитесь, что в форме выбран костюм скелета.
6. Проверьте обязательные поля заказа, неверный e-mail, согласие, сообщение после корректного заполнения и кнопку «Очистить».
7. В контактах проверьте форму обратной связи, открытие и закрытие модального окна, формат телефона и сообщение о проверке данных.
8. Через DevTools проверьте ширины 375, 768, 1024 и 1440 px: меню, сетки, изображения, формы, таблицу и модальное окно.
